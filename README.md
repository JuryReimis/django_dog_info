# django_dog_info

## Для запуска:
 - Клонируйте репозиторий
 - Используйте команду
    ```commandline
    cd django_dog_info
    cp .env.example .env  
    ```
 - Отредактируйте файл .env в соответствии со своими данными
 - Вернитесь в корень проекта
    ```commandline
    cd ..
    ```
 - Запустите докер
 - Введите команды:
    ```commandline
    docker-compose build
    docker-compose up
    ```
 - После запуска контейнера приложение готово к работе
   
## Структура проекта

### Приложение dogs
    Реализует функционал по работе с породами(breeds) и собаками(dogs)
    Взаимодействие с бд происходит через ORM Django
    В силу небольшого количества бизнес-логики все манипуляции над данными  происходят прямо в классе ViewSet

    Доступные api endpoints:
    - GET \api\breeds\ - получение списка пород
    - POST \api\breeds\ - создание новой записи по предоставленным данным
    - GET \api\breeds\<id>\ - получение записи по id
    - PUT \api\breeds\<id>\ - обновление записи по id
    - DELETE \api\breeds\<id>\ - удаление записи по id

    - GET \api\dogs\ - получение списка собак
    - POST \api\dogs\ - создание новой записи по предоставленным данным
    - GET \api\dogs\<id>\ - получение записи по id
    - PUT \api\dogs\<id>\ - обновление записи по id
    - DELETE \api\dogs\<id>\ - удаление записи по id

### Особенности
- Автоматический расчет статистики по породам
- Валидация данных при создании записей
- Оптимизированные запросы к БД
